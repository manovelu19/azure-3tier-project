# Azure 3-Tier Infrastructure Project

## Project Overview
Designed and deployed a secure 3-tier Azure infrastructure using Virtual Machines, VNets, Load Balancer,  Monitoring, and Backup solutions.

---

## Services Used
- Azure Virtual Machines
- Azure Virtual Network
- Azure Load Balancer
- Azure Monitor
- Network Security Groups
- Recovery Services Vault

---

## Architecture
Traffic is distributed through Azure Load Balancer to two Ubuntu VMs hosted inside Azure Virtual Network.

---

## Virtual Machines
- vm-web-1
- vm-web-2

---

## Features
- Load balancing
- Monitoring and alerts
- Backup configuration
- Secure networking
- High availability setup
